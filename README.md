## What I care about

- **Failures remain failures.** Instrumentation can improve; acceptance thresholds do not move after a result.
- **Intent precedes mutation.** Evidence exists before an action can change external state.
- **Direct evidence beats inference.** Ambiguous outcomes halt for reconciliation.
- **Research and execution stay separate.** Strategy code cannot import order-capable paths.
- **Reproducibility is a feature.** Public claims are backed by offline tests and hash-bound evidence.
